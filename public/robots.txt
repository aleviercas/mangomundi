# seo y aparecer en busquedas de Google o bing": robots.txt is advisory —
# it only stops crawlers that choose to honor it, which does NOT include
# an adversarial scraper hitting endpoints directly. What it DOES reliably
# stop is the major AI companies' own crawlers, which are built to respect

# and everything else under the default "*" block) keep full access —
# nothing here touches indexing/SEO — while the known AI-training/AI-answer
# crawlers are named individually and disallowed everywhere. This list
# needs occasional upkeep as new bots appear.
